# Yonah Website Engine

Premium website production base — 159 components, 20 design families, built for Claude Code.

## Quick Start

```sh
git clone https://github.com/jemimahwarren3-max/basee.git my-client
cd my-client
npm install
```

Open in Claude Code, describe the website you want, and get a production site in minutes.

## What's Inside

- **159 Astro components** across 15 categories (heroes, navigation, services, galleries, testimonials, pricing, contact, CTA, footers, FAQ, products, statistics, about, interactive, common)
- **20 design families** with distinct typography, colors, spacing, and layout tokens
- **Astro 7 + React 19** islands architecture
- **Tailwind CSS v4** for utility-first styling
- **CSS custom properties** for theming — swap a design family's tokens and every component adapts

## Commands

| Command         | Action                     |
|----------------|----------------------------|
| `npm run dev`   | Start dev server           |
| `npm run build` | Production build           |
| `npm run preview` | Preview production build |
| `npm run lint`  | Run oxlint                 |
